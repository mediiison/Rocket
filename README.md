# rocketsim

Небольшой симулятор полёта модельной ракеты на Python: тяга по кривой двигателя, сопротивление воздуха, ветер, парашют и **Монте-Карло разброс точки приземления**. Отвечает на практичный вопрос: *куда реально упадёт ракета и какая нужна задержка вышибного заряда*.

![Один полёт](assets/flight.png)

![Разброс посадки](assets/landing.png)

## Что внутри

- Интегрирование по методу Рунге-Кутты 4-го порядка с переменным шагом: мелкий на рейке, во время работы двигателя и раскрытия парашюта, крупный на спуске. Один полёт считается за ~0.03 с.
- Стандартная атмосфера ISA (0-20 км), поправка на высоту площадки и температуру.
- Ветер со степенным профилем по высоте, направление задаётся как в метеосводках (откуда дует).
- Модель двигателя: кусочно-линейная кривая тяги, масса топлива убывает вместе с выданным импульсом, задержка до вышибного заряда.
- Парашют раскрывается плавно, а не мгновенно, поэтому видны перегрузка при раскрытии и последствия слишком раннего или позднего срабатывания.
- События полёта: сход с рейки, выгорание, апогей, раскрытие парашюта, посадка - с интерполяцией момента.
- Монте-Карло: разброс ветра, наклона рейки, тяги, коэффициентов сопротивления и задержки. Результат - радиус, внутри которого садится 95% запусков.
- CLI, экспорт траектории в CSV, графики в PNG, Python API.

## Установка и запуск

```bash
cd model-rocket-sim
pip install -e ".[dev]"

rocketsim motors                                 # доступные двигатели
rocketsim fly                                    # один полёт, картинка flight.png
rocketsim mc --runs 500 --seed 1                 # разброс посадки, картинка landing.png
```

Всё настраивается флагами, например D12 с задержкой 5 с, ветер 5 м/с с юго-юго-запада и рейка, наклонённая на 5 градусов:

```bash
rocketsim fly --motor D12-5 --wind 5 --wind-from 200 --tilt 5 --csv trajectory.csv
```

| Флаг | Что задаёт |
|---|---|
| `--motor C6-5` | двигатель и задержка, пресеты `B6`, `C6`, `D12` |
| `--delay 5.5` | задержка в секундах, перекрывает значение из `--motor` |
| `--mass`, `--diameter`, `--cd` | сухая масса (г), диаметр корпуса (мм), коэффициент сопротивления |
| `--chute`, `--chute-cd` | диаметр парашюта (см, `0` - без парашюта) и его коэффициент сопротивления |
| `--wind`, `--wind-from` | скорость ветра на 10 м (м/с) и направление, откуда дует (градусы, 0 = север) |
| `--tilt`, `--tilt-az` | наклон рейки и азимут наклона (по умолчанию против ветра) |
| `--rail`, `--elevation`, `--temp-offset` | длина рейки, высота площадки, отклонение температуры от стандартной |
| `--runs`, `--seed` | для `mc`: число полётов и seed для воспроизводимости |
| `--wind-sd`, `--wind-dir-sd`, `--tilt-sd`, `--thrust-sd`, `--delay-sd` | для `mc`: разбросы входных данных |

`rocketsim mc --runs 500 --seed 1`:

Номинальный полёт садится в 187 м, но поле для запуска нужно выбирать с запасом: в 5% случаев ракета улетает дальше 317 м.

## Какая задержка нужна

У настоящих двигателей задержка выбирается из ряда 3, 5, 7 с. `examples/delay_sweep.py` показывает, что это значит для лёгкой ракеты на C6 (ветер 3 м/с):

| Задержка, с | Вертикальная скорость при раскрытии, м/с | Апогей, м | Снос, м |
|---|---|---|---|
| 3 | +27.0 | 261 | 182 |
| 4 | +15.6 | 279 | 190 |
| 5 | +5.3 | 286 | 187 |
| 5.5 | +0.3 | 286 | 183 |
| 6 | -4.5 | 286 | 176 |
| 7 | -13.9 | 286 | 156 |
| 8 | -22.6 | 286 | 128 |
| 9 | -30.3 | 286 | 93 |

Из стандартных значений ближе всего 5 с (парашют раскрывается за 0.4 с до апогея), оптимум около 5.5 с. Раннее раскрытие стоит высоты (при 3 с апогей на 25 м ниже), позднее уменьшает снос, но парашют раскрывается на скорости спуска 14-30 м/с. Выдержит ли это реальный парашют, симулятор не знает.

## Python API

```python
from rocketsim import DEFAULT_ROCKET, Conditions, get_motor, simulate, run_monte_carlo

conditions = Conditions(wind_speed=3.0, wind_from=270)
flight = simulate(DEFAULT_ROCKET, get_motor("C6-5"), conditions)
print(flight.apogee, flight.drift)            # 285.7  187.5
print(flight.events["deploy"].vz)             # скорость по вертикали при раскрытии

mc = run_monte_carlo(DEFAULT_ROCKET, get_motor("C6-5"), conditions, runs=300, seed=1)
print(mc.radius(95))                          # 317.3
```

`Flight` хранит всю траекторию (`t`, `r`, `v` как numpy-массивы), события, показания «акселерометра» (`g_load`, `g_axial`) и `summary()` со сводкой.

## Физика модели

Ракета - материальная точка с переменной массой в системе: x - восток, y - север, z - вверх.

```text
m(t) * dv/dt = T(t) * u + D + m * g
D = -1/2 * rho(h) * Cd * A * |v - w(z)| * (v - w(z))
w(z) = w10 * (z / 10 м) ^ (1/7)
```

- `T(t)` - тяга по кривой двигателя, `u` - направление тяги, `rho(h)` - плотность из ISA.
- На рейке движение разрешено только вдоль рейки. После схода с неё ось ракеты совпадает с вектором скорости относительно воздуха (идеальное флюгирование), поэтому тяга толкает против ветра, и ракета уходит на ветер.
- После срабатывания вышибного заряда площадь сопротивления `Cd * A` за 0.5 с линейно растёт от корпуса до парашюта.
- Показание акселерометра считается как `dv/dt + g`, поэтому на площадке оно равно +1 g, а в свободном падении около 0.

## Ограничения

- Три степени свободы: нет вращения, колебаний вокруг центра масс и угла атаки.
- Коэффициент сопротивления постоянный, то есть модель дозвуковая: на C6 число Маха около 0.25, на D12 около 0.4. Для быстрых ракет она не годится.
- Кривые тяги - реалистичные заменители: интегральный импульс, время работы и массы взяты порядка популярных двигателей B6, C6 и D12, а форма кривой общая. Это не сертифицированные данные производителя.
- Ветер постоянный по направлению и без порывов, разброс по запускам задаётся в Монте-Карло.
- Учебный проект. Для реальных запусков опирайтесь на данные двигателей и правила безопасности вашего клуба.

## Тесты

```bash
pytest -q
```

Проверяются, среди прочего: порядок точности RK4 (ошибка падает в 16 раз при уменьшении шага вдвое), значения ISA, интеграл кривой тяги, посадочная скорость под парашютом против аналитической скорости установившегося снижения, направление сноса при разном ветре, воспроизводимость Монте-Карло по seed, нулевой разброс даёт номинальный полёт. GitHub Actions запускает тесты на Python 3.10, 3.12 и 3.13.

```text
tests/            pytest
examples/         delay_sweep.py
assets/           картинки для README
```
